# Кинотеатр (итоговый проект)

Короче, это консольная прога про кинотеатр. Можно создавать залы,
добавлять сеансы, продавать и бронировать билеты, слать уведомления
и смотреть отчёты по продажам. Всё сохраняется в базу sqlite.

## Как запустить

Всё запускается из папки проекта. Главное демо:

    python main.py

Оно прогоняет вообще всё: залы, сеансы, продажи, бронь, допы к билетам,
базу и отчёты. Если в конце написало «всё отработало!» - значит всё ок.

Есть ещё три примера поменьше:

    python examples/demo_basic.py      # просто модели
    python examples/demo_services.py   # продажи, бронь, уведомления
    python examples/demo_full.py       # всё сразу + база

## Командная строка

Можно рулить кинотеатром прямо из терминала:

    python -m src.cinema.cli add-session "Дюна" --hall-type imax --start "2026-12-01 19:30"
    python -m src.cinema.cli list
    python -m src.cinema.cli sell 2 7 --name Вася --age 20
    python -m src.cinema.cli book 2 8 --name Маша
    python -m src.cinema.cli report

id сеанса смотри через list.

## Тесты

    pip install -r requirements.txt
    python -m pytest tests/ -v

## Что где лежит

- `config.py` - настройки: название кинотеатра, путь к базе, размер скидок
- `main.py` - демо всего сразу
- `src/cinema/models` - фильмы, залы, сеансы, билеты, люди
- `src/cinema/services` - продажи, бронь, цены, уведомления, отчёты
- `src/cinema/patterns` - фабрика, синглтон, декоратор, адаптер
- `src/cinema/database` - работа с sqlite
- `src/cinema/cli` - команды для терминала
- `src/cinema/interfaces`, `exceptions`, `utils` - интерфейсы, ошибки, мелкие утилиты
- `tests` - тесты
- `examples` - примеры

## Что тут используется

- наследование и полиморфизм — 4 типа залов, у каждого своя цена билета;
- инкапсуляция — дескриптор RangeCheck не даёт сделать зал на 100 рядов;
- абстрактные классы — свои интерфейсы (Infoable, Sellable, Bookable и т.д.);
- свои исключения — например AlreadySoldError, если место уже занято,
  и AgeLimitError, если зритель мал для фильма;
- паттерны: фабрика (делает сеансы), синглтон (реестр кинотеатров один на всех),
  декоратор (попкорн / парковка / премиум-место к билету),
  адаптер (сеанс из словаря чужой системы);
- наблюдатель — уведомления на почту и по смс при продаже;
- стратегии цены — обычная, студенческая, выходного дня, утренняя;
- база sqlite — фильмы, залы, сеансы, зрители, билеты.
